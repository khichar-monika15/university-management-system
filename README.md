# University-Management-System

A multi-role university management system providing real-time access for Admin, Instructor, and Student users, built using the MERN stack.

## Tech Stack

- Frontend: React.js
- Backend: Node.js, Express.js
- Database: MongoDB Atlas
- Real-Time Features: Role-based access for Admin, Instructor, and Student users
- Deployment: Netlify (Frontend), Render (Backend)

## Key Features

- Role-based platform with separate access for Admin, Instructor, and Student users
- Admin functionality to create instructor accounts and manage courses
- Instructors can manage student information, attendance records, and academic data
- Secure student portal for real-time access to attendance and grades
- Fully responsive, user-friendly interface with modern UI components
- Deployed on Netlify and Render for cloud-based access
